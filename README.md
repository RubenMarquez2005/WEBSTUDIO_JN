# WEB JAVI

Web oficial de WEB JAVI, estudio de producción musical, ingeniería de sonido y desarrollo creativo.

## Estado del proyecto

Primera versión frontend funcional, construida con HTML, CSS y JavaScript sin dependencias externas. Incluye las seis vistas principales, navegación responsive, carrito de tarifas, formulario de contacto, efectos visuales y una base preparada para conectar servicios reales.

## Ejecutar en local

Desde esta carpeta, ejecuta:

```bash
python3 -m http.server 8000
```

Después abre `http://localhost:8000` en el navegador.
